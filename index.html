gas_workspace

Личные скрипты Google Apps Script владельца для автоматизации его учёта.

Скрипты работают в Google Таблицах и на Google Диске владельца. Они выгружают данные из его учётных систем, строят отчёты на листах его книг, добавляют в эти книги меню и окна для расчётов и сохраняют файлы отчётов на его Диске. Тем же приложением владелец выкладывает свои скрипты, запускает их и читает журналы их выполнения.

Это не публичный сервис: регистрации нет. Скриптами пользуются только владелец и люди, которым он сам открыл доступ к своим книгам.

gas_workspace

Personal Google Apps Script automation of the owner's bookkeeping.

The scripts run in the owner's Google Sheets and Google Drive. They import data from the owner's accounting systems, build reports in the owner's spreadsheets, add menus and dialogs to those spreadsheets and save report files to the owner's Drive. The owner also uses this app to deploy the scripts, run them and read their execution logs.

This is not a public service: there is no sign-up. Only the owner and people the owner has given access to the spreadsheets use the scripts.
