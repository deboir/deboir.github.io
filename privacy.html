gas_workspace

Политика конфиденциальности

Действует с 28 октября 2026 года.

gas_workspace — личные скрипты Google Apps Script владельца и приложение, которым он их выкладывает и запускает. Пользователи приложения — владелец и люди, которым он сам открыл доступ к своим книгам.

Какие данные Google используются

  • Google Таблицы — чтение и запись книг, с которыми работают скрипты: листы отчётов, журнал операций, служебные листы.
  • Google Диск — файлы, которые скрипты создают и читают: кэш данных, сохранённые отчёты, служебная книга с настройками.
  • Меню и окна в Google Таблицах — показ меню и окон скриптов в книгах.
  • Внешние запросы — обращения к учётным системам и деловым сервисам владельца, откуда скрипты берут данные для отчётов.
  • Проекты Apps Script и журналы Google Cloud — только у владельца: выкладка его скриптов, их запуск и чтение журналов их выполнения.

Как они используются

Данные нужны только для действия, которое запустил пользователь: построить отчёт, записать лист, сохранить файл. Они не продаются, не используются для рекламы и не передаются третьим лицам. Данные из Google остаются в Google-аккаунтах владельца и пользователей. Журналы выполнения хранятся в проекте Google Cloud владельца по правилам Cloud Logging (обычно 30 дней), владелец читает их, чтобы разбирать ошибки.

Использование и передача информации, полученной из API Google, соответствуют правилам Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions. После этого скрипты перестанут работать от имени этого аккаунта.

Privacy policy

Effective October 28, 2026.

gas_workspace is the owner's personal set of Google Apps Script scripts and the app the owner uses to deploy and run them. Its users are the owner and people the owner has given access to the owner's spreadsheets.

Google data the app uses

  • Google Sheets — reading and writing the spreadsheets the scripts work with: report sheets, an operations journal, service sheets.
  • Google Drive — files the scripts create and read: data cache, saved reports, a settings spreadsheet.
  • Menus and dialogs in Google Sheets — showing the scripts' menus and dialogs in spreadsheets.
  • External requests — calls to the owner's accounting systems and business services the reports are built from.
  • Apps Script projects and Google Cloud logs — owner only: deploying the owner's scripts, running them and reading their execution logs.

How the data is used

Data is used only for the action the user started: building a report, writing a sheet, saving a file. It is not sold, not used for advertising and not shared with third parties. Data from Google stays in the Google accounts of the owner and the users. Execution logs are kept in the owner's Google Cloud project under Cloud Logging retention rules (usually 30 days); the owner reads them to investigate errors.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions. After that the scripts stop working on behalf of that account.
